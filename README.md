# PUBG Triggerbot

Download: soon

Fires on its own when the crosshair sits on a target in PUBG.

## Settings

- hit delay in ms
- trigger zone radius
- fire only on visible enemies
- single-shot or hold
- pulse length

## Run

Extract, `loader.exe` as administrator, start PUBG, toggle with F8. Keep delay around 35-55 ms, lower looks robotic.

Windows 10/11 · Steam · BattlEye. Use at your own risk.
